# ⚽ 信阳师范大学历史文化学院足球队 — 官网（全站同步版）

一个**前后端一体**的球队官网：管理员在后台修改内容后，**所有访问者刷新即可看到最新数据**（队员、照片、荣誉、背景全站同步）。

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 球队首页 | 队徽、队名、口号、建队年份与人数统计 |
| 球队简介 | 所属学院、建队年份、队训、详细介绍（后台可改） |
| 现役队员 | 卡片展示照片、号码、位置、年级，点击查看完整档案 |
| 名人堂 | 金色主题卡片，展示荣誉成就与传奇故事 |
| 球员照片 | 支持上传照片（自动压缩）或粘贴图片链接 |
| 自定义背景 | 纯色 / 图片背景 + 深色遮罩调节 |
| 权限保护 | 所有修改需管理员密码，口令经「盐 + SHA-256」存于服务器 |
| **全站同步** | 数据保存在服务器 `data/data.json`，改一次、所有人可见 |
| 数据备份 | 每次保存自动备份；支持手动导出 / 导入 JSON |

## 🚀 快速开始（本地预览）

- 方式一（最简单）：双击 `index.html`，浏览器直接打开（数据存浏览器本地，仅预览用）；
- 方式二（带服务器）：`npm install && npm start`，打开 http://localhost:3000；
- 局域网演示：双击 `start.bat`，同一 WiFi 的同学访问 http://192.168.31.65:3000。

## 🌐 让同学通过网址访问（免费部署）

> 📖 **图文教程**：双击打开项目根目录的 **`部署图文教程.html`**（无需网络，浏览器直接看），每一步都有界面示意图和检查点。

### ✅ 推荐：GitHub Pages（永久免费、无需后端/数据库/绑定支付）

1. GitHub 新建仓库（Public，如 `xysy-history-fc`），上传：`index.html`、`css/`、`js/`、`data/`（含 data.json）、`README.md`；
2. 仓库 **Settings → Pages** → Source: **Deploy from a branch** → `main` / `(root)` → Save；
3. 等 1~2 分钟，打开 `https://你的用户名.github.io/xysy-history-fc/` 即可访问；
4. 修改数据（发布流程）：后台改数据保存（草稿）→ 「系统设置 → 导出发布数据文件」→ 在仓库里替换 `data/data.json` → 约 1 分钟后全站更新。

> 特点：零成本、无支付绑定；数据公开（本来就是对外宣传页）；国内一般可访问。
> 升级说明：若以后想要"改完秒同步"，可选腾讯云 CloudBase（国内节点，但按量计费需绑定支付方式）。

### 备选：腾讯云 CloudBase（国内节点、秒同步，但需绑定支付方式）

注册腾讯云并实名认证 → 开通「云开发 CloudBase」→ 创建环境（**按量计费**，免费额度内不扣费）→ 云函数上传 `cloudfunction/api/api.zip` → 数据模型（数据库）新建 `site`/`meta`/`tokens` 三个集合 → 静态托管上传前端。详细步骤见旧版教程（可找我索取）。

### 备选：Render（免费，境外）

连接 GitHub 仓库部署，数据写回 GitHub（需配置 `GITHUB_REPO`/`GITHUB_TOKEN`）。注意 Render 为境外平台，国内访问稍慢，数据存放境外。

## 🔐 权限说明

- GitHub Pages 版：修改需要管理员密码（盐 + SHA-256 存于浏览器本地），改密码仅对当前浏览器生效——这是纯前端方案的固有限制，适用于校园宣传场景；
- 服务器版（本地/server.js）：口令存于服务器 `data/auth.json`，写操作需登录令牌。

## 📝 常见问题

- **为什么本地双击 index.html 也能用？** 检测不到 data/data.json 时自动回退到浏览器本地存储，方便离线预览。
- **GitHub Pages 版数据会丢吗？** 不会。全站数据就是仓库里的 `data/data.json`，改它并发布即全站更新；建议每次发布后把导出的 data.json 另存一份备份。
- **改完数据同学看不到？** 记得走发布流程：后台改（草稿）→ 系统设置导出 data.json → 替换仓库里的 data/data.json → 等约 1 分钟。
- **预置数据是什么？** 页面预置示例队员与名人堂，请登录后台替换为球队真实资料。
